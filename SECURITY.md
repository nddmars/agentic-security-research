# Security Policy

## Scope

This repository holds security research material intended for **defensive and
educational** purposes. Please use it responsibly and only against systems you
own or are explicitly authorized to test.

## Reporting a vulnerability

If you discover a security issue in the code or artifacts hosted here, please
report it privately rather than opening a public issue. Contact the maintainer
via GitHub ([@nddmars](https://github.com/nddmars)) and allow reasonable time
for a fix before any public disclosure.

Please include:

- A clear description of the issue and its impact
- Steps to reproduce, or a minimal proof of concept
- Any relevant environment details

Reports made in good faith are welcome and appreciated.
